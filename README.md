# Университетский вендинг — лабораторная работа 4

Проект развивает лабораторную работу 3. Теперь автомат продаёт не только кофе, но и разные товары для студентов: кофейные напитки, батончики и блюда быстрого приготовления. Это по-прежнему вендинговый автомат, а не кафе или ресторан.

## Структура проекта

- `cpp/` — C++17: исходные классы автомата из предыдущей работы, умные указатели и новая иерархия товаров.
- `csharp/` — C# (.NET 8): та же иерархия товаров на языке с управляемой памятью; классы `Ingredient`, `Money` и `SalesLog` сохранены как элементы предыдущей версии.
- `report.md` и `report_lab04.pdf` — отчёт.

## Иерархия товаров

```text
                 BaseProduct (abstract)
                 /        |           \
                /         |            \
       CoffeeProduct  SnackProduct  InstantMealProduct (final / sealed)
```

`BaseProduct` хранит общее состояние товара. `CoffeeProduct` описывает напиток, `SnackProduct` — упакованный перекус, `InstantMealProduct` — блюдо быстрого приготовления.

## C++: сборка и запуск

Требуется компилятор с поддержкой C++17. Команды выполняются из папки `cpp`.

Linux / macOS / MinGW Bash:

```bash
g++ -std=c++17 -Wall -Wextra -Wpedantic *.cpp -o vending_demo
./vending_demo
```

Windows PowerShell (MinGW):

```powershell
g++ -std=c++17 -Wall -Wextra -Wpedantic *.cpp -o vending_demo.exe
.\vending_demo.exe
```

Пример фактического вывода после сборки находится в `cpp/program_output.txt`.

В C++-проекте нет `new`, `delete` и `friend class`. Для владения используются умные указатели. В `main` сохранены демонстрации ЛР3: передача `unique_ptr` через `std::move`, массивы умных указателей, `shared_ptr::use_count()` и `weak_ptr::lock()`. `MachineOperator` хранит `std::weak_ptr<VendingMachine>`, а автомат хранит товары через `std::shared_ptr<BaseProduct>`.

## C#: сборка и запуск

Требуется .NET SDK 8 или новее. Команды выполняются из корня проекта:

```bash
dotnet build csharp/CampusVending.csproj
dotnet run --project csharp/CampusVending.csproj
```

В C# поверхностная копия демонстрируется через `MemberwiseClone()`, глубокая — через копирующий конструктор и `Clone()`. `MemberwiseClone()` оставляет ссылку `_details` общей, поэтому изменение описания через поверхностную копию видно и в оригинале. `InstantMealProduct` объявлен `sealed`. В `Program.cs` показаны псевдоним типа `using VendingCatalog = CampusVending.VendingMachine;` и `using static System.Console;`. Продажа вызывается как `SellProduct("Капучино", 150)`: второй аргумент — внесённая сумма; оператор заранее пополняет кассету размена через `AddChange()`. При недостаточной оплате или нехватке сдачи продажа отменяется без изменения остатка. Пополнять кофе и размен разрешено только при выключенном автомате; повторный запуск или остановка также отклоняются.

## Что демонстрируется

1. Абстрактный класс и три наследника, виртуальные методы и полиморфизм.
2. `protected`-метод `Header()` для общего форматирования описания.
3. Конструкторы по умолчанию, с параметрами, копирования и перемещения в C++.
4. Виртуальный деструктор и уничтожение объектов через `std::unique_ptr<BaseProduct>`.
5. Поверхностное копирование общей карточки `ProductDetails` через `std::shared_ptr` и глубокое копирование через копирующий конструктор / `Clone()`.
6. Переопределение `Describe()` с вызовом базовой реализации и без неё.
7. Работа со строками: конкатенация, `find`, `substr`, сравнение.
8. `this`: самоприсваивание, возврат `*this`, передача текущего объекта автомату.
9. Статический счётчик созданных товаров.
10. Продажа кофе, батончиков и лапши через каталог автомата с проверкой оплаты и сдачи.
11. Сравнение товаров C# с учётом специальных характеристик каждого типа.

## Примечание о проверке

C++-часть собрана и запущена с предупреждениями `-Wall -Wextra -Wpedantic`, дополнительно проверена AddressSanitizer и UndefinedBehaviorSanitizer. В среде подготовки не установлен .NET SDK (`dotnet` отсутствует), поэтому C#-часть подготовлена под .NET 8, но локально не компилировалась. Перед сдачей выполните две команды из корня проекта: `dotnet build csharp/CampusVending.csproj` и `dotnet run --project csharp/CampusVending.csproj`.
