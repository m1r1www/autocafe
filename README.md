# Кафе-автомат

Курсовой проект по дисциплине «Программирование».  
**Тема:** Проектирование системы «Кафе-автомат».  
**Выполнил:** Степкин М. А., группа ПИ-53.  
**Преподаватель:** Рахманин Данила Сергеевич.

## Описание

Консольное приложение, моделирующее работу кафе-автомата:
- просмотр меню блюд;
- формирование заказа;
- расчёт стоимости;
- имитация оплаты;
- сохранение истории заказов.

## Стек

- **Язык:** C++ (стандарт C++17)
- **Сборка:** g++ / CMake
- **Данные:** текстовые файлы (menu.txt, orders.txt)

## Сборка и запуск

```bash
g++  *.cpp -o app
./app
