# Кафе-автомат — лабораторная работа №2

Учебный проект по ООП на C++17. Модель описывает автомат приготовления и выдачи напитков, ингредиенты и оператора обслуживания.

## Состав проекта

- `ingredient.hpp` / `ingredient.cpp` — класс `Ingredient`.
- `vending_machine.hpp` / `vending_machine.cpp` — класс `VendingMachine`.
- `machine_operator.hpp` / `machine_operator.cpp` — класс `MachineOperator`.
- `main.cpp` — демонстрация сценариев лабораторной работы.
- `tests.cpp` — проверки правил предметной области.
- `build.sh` — сборка без CMake.

## Сборка и запуск

Требуется `g++` с поддержкой C++17.

```bash
g++  *.cpp -o app
./app
```

## Что демонстрирует `main.cpp`

1. Объект со статическим временем жизни, ссылку и указатель.
2. `new/delete`, динамический массив объектов и массив указателей на динамически созданные объекты.
3. Композицию: `VendingMachine` хранит `Ingredient` по значению и уничтожает их вместе с собой.
4. Агрегацию: `MachineOperator` хранит указатели на отдельно созданные автоматы и не владеет ими.
5. Корректный заказ и несколько отказов по правилам предметной области.
6. Порядок уничтожения объектов.
