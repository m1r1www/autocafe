# Кафе-автомат: ЛР 3, часть 1 (C#)

Перенос трёх классов из ЛР 2 (`Ingredient`, `VendingMachine`, `MachineOperator`) на C#.
Для демонстрации освобождения ресурса добавлен небольшой класс `SalesLog` (журнал продаж),
для демонстрации разницы между классом и структурой — структура `Money`.

## Состав

Всё лежит в папке `csharp/`, один класс — один файл:

- `Ingredient.cs` — ингредиент (запас и вместимость);
- `VendingMachine.cs` — автомат, внутри него создаётся ингредиент «Кофе» (композиция);
- `MachineOperator.cs` — оператор, получает готовый автомат снаружи (агрегация);
- `SalesLog.cs` — журнал, реализует `IDisposable`;
- `Money.cs` — структура (тип-значение);
- `Program.cs` — демонстрационная программа;
- `csharp.csproj` — файл проекта.

Рядом: `output.txt` — эталонный вывод программы.

## Требования

.NET SDK 8 или новее (проверено на .NET 8). Среда разработки не нужна.

## Сборка и запуск

Команды выполняются из папки проекта (где лежит этот файл). Создавать проект командой
`dotnet new` не нужно: файл `csharp.csproj` уже есть.

```
dotnet build csharp
dotnet run --project csharp
```

Папки `bin/` и `obj/` в репозиторий не попадают (см. `.gitignore`).

## Если в консоли вместо русских букв вопросительные знаки

Windows: выполнить `chcp 65001` и запустить программу заново. Кодировка вывода в самой программе
уже включена (первая строка `Main`).

## Что показывает программа

1. Ссылки и копии: присваивание объекта класса копирует ссылку, присваивание структуры копирует значение.
2. Композиция, агрегация и проверка правила (кофе закончился, автомат выключен).
3. Освобождение ресурса: `using` и `Dispose()`.
4. Сборщик мусора: объект без ссылок живёт до сборки (`WeakReference` и `GC.Collect()`).
